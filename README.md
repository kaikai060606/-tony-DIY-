# 做自己的 Tony · REDcowork 纯前端版

此目录是独立的前端作品。上传此目录的内容即可，不要上传外层完整仓库。

## 运行与构建

- 安装：`npm install`
- 本地预览：`npm run dev`
- 静态构建：`npm run build`
- 发布目录：`out`（纯 HTML、CSS、JavaScript 和素材）

无需 Python、数据库、API Key、环境变量或后端服务。Next.js 仅用于开发和构建，发布后不需要 Node 服务。静态产物需通过网站服务访问，不要直接双击 HTML。

## 功能范围

保留视频浏览、照片选择、发色情况调整、方案展示、商品展示、教程步骤、计时、本地档案以及浏览器中的试色和转场录制。

识别结果、商品价格、方案和生成效果为预设演示数据，不执行云端 AI 推理。页面顶部明确提示演示模式。档案保存在当前浏览器，清除网站数据会删除档案。上传照片读取到本机浏览器，不上传服务器。

实时试色使用浏览器端 MediaPipe，首次加载仍需访问外部模型 CDN；摄像头和录制依赖浏览器授权及 HTTPS（本机 localhost 也可以）。语音识别取决于浏览器支持，部分浏览器可能使用其自身在线语音服务；文字和按钮操作可用。

色卡数据从原仓库公开参考表导出为本地 TypeScript 数据，不包含原数据库或用户档案。

## REDcowork 导入提示

请保留本作品的页面与交互，按纯前端方式运行。数据使用项目内置示例及浏览器本地存储，不添加后端、服务端接口或密钥。构建命令为 npm run build，静态发布目录为 out。

## 商品资料来源
商品来自原项目 knowledge-base/products/product-recommendation-rag.json，保留记录 ID、商品 ID、来源链接和采集日期。使用 public/product-assets 中原图。按色系和染色/固色类型检索；不保证染后效果等同目标。价格为历史采集价，区间按上限做一份预算演示，并非真实用量或实时成交价。
